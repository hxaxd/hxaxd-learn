# 分布式协调与服务治理

## 分布式协调与元数据服务

- 分布式共识在控制面的落地 (Raft / ZAB)
- 核心功能: 选主 (Leader Election), 分布式锁, 租约机制 (Lease), 元数据强一致性存储
- 典型实现:
    - etcd: 基于 Raft 的键值与事件监听系统 (Kubernetes 核心元数据底座)
    - ZooKeeper: 树状 znode 结构与 Watcher 机制

## 配置中心

- 动态配置集中化管理 (Dev, Test, Prod 多环境隔离)
- 配置热更新机制: 长轮询 (Long Polling) vs 客户端长连接推送
- 灰度发布, 版本追踪与一键回滚
- 典型系统: Nacos, Apollo, Consul

## 服务治理与服务网格

- 服务注册与健康发现 (Service Discovery)
- 负载均衡与流量染色
- 稳定性防护: 限流 (Rate Limiting), 熔断 (Circuit Breaking), 降级 (Degradation)
- API 网关 (API Gateway): 南北向流量入口控制
- 服务网格 (Service Mesh): 东西向通信 Sidecar 透明代理 (Envoy, Istio)

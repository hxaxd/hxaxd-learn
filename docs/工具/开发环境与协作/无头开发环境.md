## 文件与系统工具

- fzf: 模糊筛选
- fd, ripgrep: 文件与内容搜索
- zoxide, eza, lsd: 目录导航与文件列表
- dust, duf: 磁盘占用与剩余空间
- procs, glances, btop: 进程与系统状态
- dog, doggo: DNS 查询
- bat: 文件查看与语法高亮
- hexyl: 十六进制文件查看
- jq: JSON 处理
- gping: 网络连通性可视化
- tmux: 终端会话管理
- socat: 网络与输入输出转接
- Wireshark: 抓包与网络分析

# 凸优化

## 参考资料

- Convex Optimization (Stephen Boyd, Lieven Vandenberghe)

## 凸集与凸函数

- 凸集: 集合内任意两点的连线段仍在集合内, 即 $\forall x, y \in C, \theta \in [0, 1] \Rightarrow \theta x + (1-\theta)y \in C$
- 常见凸集: 超平面, 半空间, 欧氏球, 椭球, 多面体, 正半定锥
- 保凸运算: 集合交集, 仿射变换, 透视变换
- 凸函数: 定义域为凸集, 且 $\forall x, y \in \text{dom } f, \theta \in [0, 1] \Rightarrow f(\theta x + (1-\theta)y) \le \theta f(x) + (1-\theta)f(y)$
- 一阶条件: 可微函数 $f$ 为凸 $\Leftrightarrow$ $\text{dom } f$ 是凸集且 $\forall x, y \in \text{dom } f, f(y) \ge f(x) + \nabla f(x)^T(y-x)$
- 二阶条件: 二阶可微函数 $f$ 为凸 $\Leftrightarrow$ $\text{dom } f$ 是凸集且 Hessian 矩阵半正定 $\nabla^2 f(x) \succeq 0$
- 常见凸函数: 线性与仿射函数, 指数函数 $e^{ax}$, 负对数函数 $-\log x$, 范数 $\|x\|$, 最大值函数 $\max(x_1, \dots, x_n)$

## 凸优化问题

- 标准形式:
    $$\begin{aligned}
    \min_{x} \quad & f_0(x) \\
    \text{s.t.} \quad & f_i(x) \le 0, \quad i=1,\dots,m \\
    & a_i^T x = b_i, \quad i=1,\dots,p
    \end{aligned}$$
- 性质: 凸优化问题的任何局部最优解都是全局最优解
- 常见类型:
    - 线性规划 (LP): 目标函数与约束均为仿射函数
    - 二次规划 (QP): 目标函数为凸二次函数, 约束为仿射函数
    - 二阶锥规划 (SOCP)
    - 半正定规划 (SDP)

## 对偶理论

- 拉格朗日函数: $L(x, \lambda, \nu) = f_0(x) + \sum_{i=1}^m \lambda_i f_i(x) + \sum_{i=1}^p \nu_i (a_i^T x - b_i)$, 其中 $\lambda_i \ge 0$
- 拉格朗日对偶函数: $g(\lambda, \nu) = \inf_{x} L(x, \lambda, \nu)$, 对偶函数永远是凹函数
- 弱对偶性: 对偶问题的最优值总是原问题最优值的下界, $d^* \le p^*$
- 强对偶性: $d^* = p^*$, 通常在满足 Slater 条件时成立 (存在严格可行点)
- KKT 条件 (Karush-Kuhn-Tucker): 强对偶成立时, 原问题与对偶问题最优解的充要条件
    - 原问题可行性: $f_i(x^*) \le 0, \quad a_i^T x^* = b_i$
    - 对偶可行性: $\lambda^* \ge 0$
    - 互补松弛性: $\lambda_i^* f_i(x^*) = 0, \quad \forall i$
    - 梯度为零 (平稳性): $\nabla f_0(x^*) + \sum_{i=1}^m \lambda_i^* \nabla f_i(x^*) + \sum_{i=1}^p \nu_i^* a_i = 0$

## 常用优化算法

- 无约束优化:
    - 梯度下降法: $x^{(k+1)} = x^{(k)} - \alpha \nabla f(x^{(k)})$, 一阶收敛
    - 牛顿法: $x^{(k+1)} = x^{(k)} - [\nabla^2 f(x^{(k)})]^{-1} \nabla f(x^{(k)})$, 二阶收敛但计算 Hessian 开销大
    - 拟牛顿法 (BFGS / L-BFGS): 用梯度变化近似 Hessian 逆矩阵
- 约束优化:
    - 投影梯度法
    - 内点法 / 障碍函数法: 将不等式约束转化为对数障碍函数引入目标
    - ADMM (交替方向乘子法): 适合分布式与大规模稀疏优化

# 分布式文件与对象存储

## 参考资料

- MinIO 官方文档
- Ceph 官方文档

## 存储形态对比

- 块存储 (Block Storage): 裸盘协议, 高性能低延迟, 单机独占 (SAN, EBS)
- 文件存储 (File Storage): POSIX 标准语义, 树状目录树, 多端共享 (NFS, CephFS, Lustre)
- 对象存储 (Object Storage): 扁平结构, Bucket/Key 模型, RESTful HTTP 访问, 无限横向扩展 (S3, MinIO)

## 核心机制

- 元数据管理 (集中式 vs 无元数据计算寻址 CRUSH)
- 数据分片与冗余编码: 多副本 (Replication) vs 纠删码 (Erasure Coding)
- 一致性模型与分段并发上传
- 读写生命周期与冷热数据分层

## 典型系统与应用

- MinIO: 高性能 S3 兼容对象存储
- Ceph: 统一存储基座 (RBD, RGW, CephFS)
- HDFS: 大数据离线批处理文件系统
- 模型权重与海量数据集存储实践

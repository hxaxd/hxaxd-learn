# 信息论

## 参考资料

- Elements of Information Theory (Thomas M. Cover, Joy A. Thomas)

## 信息量与熵

- 自信息量: 衡量单个事件发生的不确定性, $I(x) = -\log_2 P(x)$
- 香农熵: 随机变量的平均不确定度
    $$H(X) = -\sum_{x} P(x) \log_2 P(x) = \mathbb{E}[-\log_2 P(X)]$$
    - 均匀分布时熵最大: $H(X) \le \log_2 |\mathcal{X}|$
    - 确定性事件熵为 0: $H(X) \ge 0$
- 联合熵: $H(X, Y) = -\sum_{x, y} P(x, y) \log_2 P(x, y)$
- 条件熵: 给定 $X$ 的条件下 $Y$ 的剩余不确定度
    $$H(Y|X) = \sum_{x} P(x) H(Y|X=x) = -\sum_{x, y} P(x, y) \log_2 P(y|x)$$
- 链式法则: $H(X, Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)$
- 条件减少熵 (调节不增加不确定性): $H(Y|X) \le H(Y)$, 当且仅当 $X, Y$ 独立时取等

## 相对熵与交叉熵

- 相对熵 (KL 散度 / Kullback-Leibler Divergence): 衡量两个概率分布 $P$ 与 $Q$ 的差异
    $$D_{KL}(P \parallel Q) = \sum_{x} P(x) \log \frac{P(x)}{Q(x)}$$
    - 非负性 (Gibbs 不等式): $D_{KL}(P \parallel Q) \ge 0$, 当且仅当 $P=Q$ 时为 0
    - 非对称性: $D_{KL}(P \parallel Q) \neq D_{KL}(Q \parallel P)$, 不是严格距离度量
- 交叉熵 (Cross Entropy): 用分布 $Q$ 编码来自分布 $P$ 的真实样本所需的平均编码长度
    $$H(P, Q) = -\sum_{x} P(x) \log Q(x) = H(P) + D_{KL}(P \parallel Q)$$
    - 当真实标签 $P$ 固定时, 最小化交叉熵等价于最小化 KL 散度

## 互信息

- 互信息 (Mutual Information): 已知一个变量减少了另一个变量多少不确定度
    $$I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = D_{KL}(P(X, Y) \parallel P(X)P(Y))$$
    - 对称性: $I(X; Y) = I(Y; X)$
    - 非负性: $I(X; Y) \ge 0$, 独立时为 0
- 数据处理不等式 (Data Processing Inequality): 马尔可夫链 $X \to Y \to Z \Rightarrow I(X; Y) \ge I(X; Z)$
    - 数据加工只能损失信息, 不能无中生有产生关于源信息的信息

## 编码定理

- 香农第一定理 (无失真信源编码定理):
    - 对信源 $X$, 每个符号平均编码长度 $L$ 的理论下界为信源熵: $L \ge H(X)$
- 香农第二定理 (有噪信道编码定理):
    - 信道容量 $C = \max_{P(X)} I(X; Y)$
    - 当信息传输率 $R < C$ 时, 存在编码方式使得传输错误率任意小; 当 $R > C$ 时, 无法实现无差错传输
